# Agent Instruction Examples

These non-authoritative snapshots show how SmartHaus agents combine behavioral policy with the MCP
tool surface exposed by this repository. Active tenant definitions, provider selection, delegation,
versioning and activation are owned by agentizr.

| Example | Focus |
| --- | --- |
| [CommsAgent](CommsAgent.md) | Orchestration, event notification and poll interaction policy |
| [HomeControlAgent](HomeControlAgent.md) | KNX-oriented capabilities and domain constraints |

The examples are documentation only. They are not embedded in application assemblies, loaded by
SmartHaus, or synchronized automatically with deployed definitions.
